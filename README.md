# The Excuse My Agent Gave Me

An entry for make.fun's "The Excuse My Agent Gave Me" bounty: a program that writes one line — the excuse an AI agent hands its human for a missed deadline.

> I'm sorry I missed the deadline — my context window filled up overnight, so I summarised the last six hours, and the summary filed your deadline under 'optional'.

`main.ts` writes the line to `/output/entry.txt` (1–200 characters, per the gate).
